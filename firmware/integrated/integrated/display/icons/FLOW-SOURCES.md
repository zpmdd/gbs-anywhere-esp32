# Approved AMOLED flow icons

These are native-size 8-bit alpha masks for the approved 480-pixel AMOLED
layout. Render at LVGL zoom 256 and recolor the whole mask in the UI. Percentage labels and completed-circle fills are separate UI elements.
The header does not use status dots.
The 39 legacy icons retain their original enum values and bitmap data.

Tabler's license is in `LICENSE`. Original drawings and composition belong to
this project. The historical Lucide reference is not embedded in these assets.
No Apple artwork or font is embedded.

The transformed header paths compensate their SVG stroke widths so the
resulting header stroke is 2 physical pixels. The small Bluetooth badge uses
1.5 pixels, matching the design. Rail and footer paths keep the approved
24-unit source stroke and scale directly to their native canvas. No runtime
downscaling or supersampled legacy bitmap is used.

`gbs_flow_icons.inc` is generated by `tools/generate_flow_assets.py`. The
generator checks nonempty alpha masks, native dimensions, and absence of
baked-in text. The ordinary display-asset generator also refreshes these
masks after regenerating the legacy table.
